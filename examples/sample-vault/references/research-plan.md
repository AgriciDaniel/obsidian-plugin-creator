# Research Plan

The source ledger and claim ledger record the current supported statements. Rejected sources and gaps remain in the reports. The private research reports are omitted from this public edition; reviewed public summaries remain in `references/public-sources.json`.

Refresh monthly and before release. Prioritize changed API signatures, directory policies, compatibility requirements, and security/storage behavior. Verify a specific second source before treating a high-stakes or numeric statement as corroborated.

Open work: actual desktop/device behavior, representative plugin trials, buyer validation, and benchmarked performance. These are acceptance gaps rather than missing source-pack placeholders.

The creator toolchain report adds exact sample-build and peer-dependency contracts. The retained source starter build results are separate execution evidence in references/verification/creator-builds.json.
