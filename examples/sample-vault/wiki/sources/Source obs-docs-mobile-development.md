# Source obs-docs-mobile-development

Original paraphrase of [Obsidian Developer Docs: Mobile development](https://docs.obsidian.md/Plugins/Getting+started/Mobile+development); reviewed 2026-11-01.

- Node.js and Electron APIs are unavailable on mobile. Plugins requiring these APIs must declare desktop-only support.
- The guide documents desktop mobile-layout emulation and separate real-device debugging procedures for Android and iOS; emulation is not physical-device validation.
