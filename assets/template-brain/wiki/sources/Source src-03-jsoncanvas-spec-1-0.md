Original paraphrase of [JSON Canvas Spec 1.0](https://jsoncanvas.org/spec/1.0/); reviewed 2026-11-01.

- JSON Canvas 1.0 represents an infinite canvas as optional nodes and edges arrays; nodes carry IDs, types, geometry, and optional colors.
- The specification distinguishes text, file, link, and group nodes; edges connect node IDs and may specify sides, ends, colors, and labels.
