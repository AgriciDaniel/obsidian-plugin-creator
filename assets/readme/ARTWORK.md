# README artwork

The cover is an original AI-generated illustration created with the built-in
imagegen tool on 2026-11-02. It is a visual metaphor for the creator workspace,
not a screenshot of Obsidian or an implemented plugin. The workflow SVG is an
original vector diagram matching the cover palette.

The animated `hero.svg` is an original vector scene authored on 2026-11-02.
Its pixel vault keeper feeds an idea card to a floating amethyst crystal,
plugin blocks assemble, a capsule launches, and the keeper celebrates.
The twelve second CSS loop and the matching animated workflow use no scripts,
external images, fonts, or network requests. They honor reduced motion. The
README uses the original raster cover when reduced motion is preferred.

The motion refinement replaces stepped arm and assembly poses with continuous
easing. Moving geometry uses subpixel rendering while the stationary pixel
lettering retains its grid. Compound paths replace hundreds of separate letter
rectangles. The effects animate transforms and opacity, without blur filters or
an animated stroke-dash offset. The workflow labels remain fully visible while
progress bars advance beneath them.

The workshop links to Creator Studio. Four clickable quest cards route readers
to discovery, architecture, creation, and verification. A native disclosure
offers three starter prompts. Cards wrap into a single column on small screens.

Local motion samples are recorded separately from browser frame callbacks in
`references/verification/readme-motion-2026-11-02.json`. Frame callback cadence
does not guarantee the same rendering performance on every reader's device.

Brainstein's animated Tesla workshop was the reference for the self-contained
SVG format and narrative progression. The character, scene, and animation here
are original. This is conceptual artwork, not evidence of product execution.

## Cover prompt

Use case: stylized-concept.
Asset type: wide GitHub README cover for Obsidian Plugin Creator, an independent second brain for creating Obsidian plugins.
Primary request: a beautiful, meticulously composed premium pixel art title screen, wide landscape about 2.5:1. Retro computer workshop meets an interconnected knowledge vault.
Scene: deep midnight aubergine background, warm off-white pixel typography, violet crystal light, restrained burnt orange and lavender accents. On the right half, a detailed isometric pixel workbench with a small retro computer showing linked notes, an open notebook, modular plugin blocks, and a faceted purple crystal levitating above its pedestal. Fine orthogonal paths connect little note cards to the workshop. A few tiny four-point stars, stepped borders, subtle pixel shadows. Charming and sophisticated, crisp pixels, limited palette, no photographic texture or smooth 3D.
Composition: generous negative space for large crisp readable title on the left, right hand illustration, aligned small header and footer. At least 6% safe padding around every text element.
Text verbatim: small header "DANIEL AGRICI"; very large title in three lines "OBSIDIAN" then "PLUGIN" then "CREATOR"; small subtitle "A second brain for your next plugin." Small bottom text "IDEA  /  PLAN  /  BUILD  /  REFINE".
Typography: custom legible blocky pixel lettering, large enough to read in GitHub at 800px wide.
Constraints: original artwork, no official endorsement, no certification or approval badges, no em or en dash characters, no watermark. No extra text. Opaque background.
