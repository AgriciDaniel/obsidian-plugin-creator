# Entities Hub

This hub keeps the `wiki/entities/` layer navigable. It is not a dumping ground; every note here should earn its place by linking to sources, flows, deliverables, decisions, or seed unknowns.

## Parent

- [[Index]]

## Core Links

- [[Home]]
- [[Overview]]
- [[Dashboard]]
- [[CONVENTIONS]]
- [[Tag Taxonomy]]

## What Belongs Here

- Notes whose primary `type` matches this hub or directly supports this hub's workflow.
- Notes that can name their source need, confidence level, owner, and related operating path.
- Notes that link back to this hub and at least two other vault notes.
- Notes that can be maintained without reading private `.raw/` material first.

## What Does Not Belong Here

- Raw pasted source material; put immutable captures under `.raw/` and summaries under [[Source Manifest Guide]].
- Unsourced domain claims; open a gap or question note instead.
- Deliverable prose that has no path back to [[Health Scorecard]], [[Action Roadmap]], or [[Weekly Report]].
- One-off scratch notes that should live in [[Activity]] or [[Home]] until they become stable.

## Maintenance Loop

1. Read [[Dashboard]] for seed, stale, and contested notes.
2. Open [[Tag Taxonomy]] and confirm this hub's notes carry the right `#type/` tag.
3. Check each note's `related` frontmatter for real reciprocal links.
4. Check body links for a path to [[Source Intake Workflow]] or [[Claim Verification Flow]].
5. Move unresolved evidence into [[wiki/gaps/_index|Gaps Hub]].
6. Move unresolved research decisions into [[wiki/questions/_index|Questions Hub]].
7. Move falsifiable checks into [[wiki/experiments/_index|Experiments Hub]].
8. Update [[Activity]] when the hub's shape changes.

## Minimum Note Shape

- Answer-first summary.
- Source need or source list.
- Confidence value from [[Tag Taxonomy]].
- Related links with enough context for the next reader.
- Caveat for stale, contested, or single-source evidence.
- Next action when the note is not evergreen.
