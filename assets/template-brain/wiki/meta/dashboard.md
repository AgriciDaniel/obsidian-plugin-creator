# Dashboard

This local advisory brain covers all eight plugin scopes through 16 architecture topics and 121 dated source entries. Begin with [[Plugin Architecture Matrix]], then follow the matching concept and its official source notes.

## Use the brain

1. Define the user task, input data, target platforms, and release channel.
2. Choose a surface with [[Plugin Architecture Matrix]].
3. Read the concept, [[Research Pack]], and the actual official source.
4. Run a read-only repository scan using the source checkout's `review-plugin` command.
5. Record real execution separately in [[Runtime Acceptance Matrix]].

## Current evidence

The corpus is researched; the static adapter is tested with synthetic fixtures. Actual Obsidian execution, physical devices, public submission, and paid demand are unverified. Audit scores measure local gates and structure only.
