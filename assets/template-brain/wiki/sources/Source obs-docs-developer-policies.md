# Source obs-docs-developer-policies

Original paraphrase of [Obsidian Developer Docs: Community Directory Developer Policies](https://docs.obsidian.md/Community+directory/Developer+policies); reviewed 2026-11-01.

- Community directory policies prohibit code obfuscation, client-side telemetry, dynamic network ads, and self-installation or self-updates.
- README disclosures are required for network services, access outside vaults, payment or account requirements, in-plugin static ads, and server-side telemetry with a privacy policy.
