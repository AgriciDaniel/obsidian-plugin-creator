Original paraphrase of [Obsidian Help: Sync settings and selective syncing](https://help.obsidian.md/sync/settings); reviewed 2026-11-01.

- Dot-prefixed hidden files and folders are excluded from Obsidian Sync except the active configuration folder. Community plugin syncing requires enabling its configuration options.
- The help page distinguishes device-specific Sync settings from synced vault configuration and links onExternalSettingsChange for plugin settings refresh.
