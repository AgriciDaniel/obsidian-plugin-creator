# Start here

Open `assets/template-brain/` in Obsidian and start at **Plugin Creator Studio**.
This is the public knowledge snapshot. Its 121 public references and 200 original
paraphrased claims are in `references/public-sources.json`.

For your own working vault, run from the complete source checkout:

```bash
python3 -m obsidian_plugin_brain new my-plugin-brain --owner "Your name" --out-dir ../my-plugin-vaults
```

Open that new folder in Obsidian. Local intake and Obsidian configuration belong
there, outside this public checkout.

The generated vault also includes the category palette and seven saved graph views. In Obsidian Bookmarks, expand **Plugin Creator graph views**. See [Graph Views](assets/template-brain/wiki/meta/Graph%20Views.md). The checked-in template and sample are knowledge snapshots; create a working vault to activate the graph settings.
