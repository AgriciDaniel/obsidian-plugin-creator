# Source SRC-01-005

Original paraphrase of [Obsidian Community directory developer policies](https://github.com/obsidianmd/obsidian-developer-docs/blob/1c26772ac13d6e9870c865936d389fdfe694e742/en/Community%20directory/Developer%20policies.md); reviewed 2026-11-01.

- Directory-listed plugins must not obscure their code purpose, add client-side telemetry, or install or update themselves or their dependencies.
- Network use, required payment or accounts, external vault file access, in-plugin static advertising, and server-side telemetry require README disclosures; server-side telemetry also requires a privacy policy.
- Directory policies require a license, respect for third-party code licenses, and compliance with the Obsidian trademark policy.

Public reference ID: `SRC-01-005`. The public catalog retains dates, confidence, and upstream references. Private research captures are not distributed.
