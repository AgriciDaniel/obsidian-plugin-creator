# Source obs-help-plugin-security

Original paraphrase of [Obsidian Help: Plugin security](https://help.obsidian.md/plugin-security); reviewed 2026-11-01.

- Obsidian cannot reliably restrict enabled plugins to individual permissions; plugins inherit its access. Restricted mode prevents third-party plugin execution.
- The help page states that every plugin version is scanned and directory pages display safety scorecards; manual reviews continue for popular, featured, and flagged plugins.
