# Changelog

All notable changes to Obsidian Plugin Brain are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this repository adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-11-02

### Added

- Obsidian Plugin Creator workflow with discovery, architecture, UX/accessibility, data/migrations, implementation, verification/performance, release/maintenance, debugging, and advanced surfaces.
- Eight starter archetypes with a validated brief, explicit workspace boundary, dry-run, no overwrite, known vault-marker checks, and generated-file SHA256 receipts.
- Exact dependency lock, TypeScript/esbuild configuration, official lint, and actual compiler/bundle/lint evidence for all eight templates.
- Eight reusable project contracts, creator quality rubric, updated starting guide, and a separate curated starter ZIP.
- Offline generation/privacy regressions and exclusion of node_modules and receipt-marked user projects from brain packaging.

### Boundaries

- Generation creates new source artifacts only. It performs no dependency installation, plugin execution, active installation, note writes, or publication. Actual runtime, physical-device, and public review results remain separate.
- The exact current toolchain includes an explicit lint-package Obsidian peer override and transitive ESLint 9 dependencies beneath the ESLint 10 runner; reevaluate on refresh.

## [0.1.0] - 2026-11-01

### Added

- Scaffolded and adapted `obsidian-plugin-brain` (`spec_version: 3`, `fable-grade`) across all eight Obsidian plugin engineering scopes: core lifecycle, custom `ItemView` and Bases dashboards, 2D Canvas and 3D WebGL visuals, CodeMirror 6 Live Preview and Reading view parity, Vault and `MetadataCache` engines, UI frameworks and bundlers, iOS and Android mobile hardening, and Community Store submission gates.
- Distilled 16 authoritative canon references (`references/canon/001` through `016`) and folded all 16 into interlinked wiki concept notes (`assets/template-brain/wiki/concepts/`) backed by dated primary sources in `references/public-sources.json` and `references/public-sources.json`.
- Implemented the zero-dependency static plugin analyzer package (`obsidian_plugin_brain/importers/plugin_repo.py`, `obsidian_plugin_brain/synthesis/review_health.py`, `obsidian_plugin_brain/reports/readiness_report.py`, and `scripts/plugin_review_audit.py`) with JSON Schemas (`references/schemas/`) and deterministic fixtures (`tests/fixtures/obsidian-plugin/`).
- Added multi-scope Obsidian canvases (`Onboarding Canvas.canvas`, `Plugin Scopes Decision Map.canvas`, `Review and Submission Pipeline.canvas`), native Obsidian Bases dashboard (`wiki/meta/dashboard.base`), dash-free SVG architecture assets, and byte-deterministic sample vault (`examples/sample-vault/`).

### Recovered and verified

- Recovered the interrupted research build with 118 source entries, 194 paraphrased claims, immutable report captures, and explicit SINGLE-SOURCE limits.
- Repaired the importer, source-bound rule catalog, missing-data handling, scan limits, mobile module detection, and malformed compatibility reporting.
- Distinguished static signals from actual build, lint, runtime, device, and submission evidence.
- Prevented client synthesis from rewriting product canon and retained inherited raw provenance when creating a vault.
- Added a fixed-date demo with retained SHA256 checks, operator guidance, a continuation prompt, and observed verification results.
