# Action Roadmap

1. Define the actual plugin's task, input data, platforms, and release channel.
2. Use [[Plugin Architecture Matrix]] and the matching concept to choose a minimal implementation.
3. Run the source checkout's static review on the actual plugin repository.
4. Complete the real build, official lint, and [[Runtime Acceptance Matrix]].
5. Refresh official policies before any submission, then obtain owner approval.

## Research maintenance

Review [[Research Pack]] monthly and immediately before releases. Retain a new report when a claim changes. Preserve existing `.raw/` evidence. Resolve high-stakes and numeric claims with a specific second-source check before stronger promotion.

## Approval boundary

Local advisory work is the V1 product. No user accounts, plugin directories, private vault content, publication, or production data are mutated by the analyzer. Publishing and external actions need the owner's explicit authorization.
